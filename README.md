# 수시 입결 검색 (2023~2026)

대학어디가(adiga.kr) 대학 발표자료 정리본을 검색할 수 있게 만든 **정적 웹사이트**입니다.
로그인·서버·빌드 없이 브라우저에서 바로 돌아갑니다.

**▶ 사이트: https://jihugwak.github.io/susi-search/**

- 데이터: 대학어디가 발표자료 정리본 (남악고 김현석, ver 07.03) · 2023~2026학년도 수시 **57,139건**
- 입결은 참고용입니다. 대학이 발표한 자료의 집계 시점·기준에 따라 실제 요강과 다를 수 있습니다.

---

## 기능 (탭 5개)

| 탭 | 내용 |
|---|---|
| **검색** | 대학·학과·전형 자동완성 검색 + 학년도/지역/전형유형/계열/소계열 필터. 내 내신 등급을 넣으면 70%컷 대비 **안정·적정·도전·어려움** 판정과 컷과의 차이(±)를 표시. 행 클릭 시 연도별 추이 그래프 |
| **대학 분석** | 원본 `NEW대학분석` 시트와 같은 4개년(2026~2023) 매트릭스. 70%컷·50%컷·모집인원·경쟁률·실경쟁률·추합 지표를 켜고 끔 |
| **집계·연도비교** | 원본 `연도비교` 피벗 재현. 1·2차 기준으로 묶어 연도별 값을 나란히 놓고 최근 두 해의 변화량 표시 |
| **등급 변환** | 백분위 ↔ 등급 변환표 (원본 `자체등급변환`) |
| **대학 링크** | 대학별 어디가 입시결과 팝업·입학처 링크 206개 |

차트는 외부 라이브러리 없이 인라인 SVG로 직접 그립니다. 런타임 의존성 0개.

## 구조

```
index.html   마크업 + 스타일 (탭 5개)
app.js       전체 로직 (검색/필터/집계/차트/모달)
data.js      수시 입결 57,139행   ─┐
links.js     대학 링크 206개       ├ 빌드 산출물, 직접 수정하지 말 것
grade.js     등급 변환표 1,000행  ─┘
```

`data.js`는 용량 때문에 **컬럼 지향 + 사전 인코딩** 형태입니다 (4.8MB).

```js
window.ADIGA_DATA = {
  n: 57139,
  dicts: { 지역:[...], 대학:[...], "교과/종합":[...], 전형:[...], 학과:[...], "인문/자연":[...], 소계열:[...] },
  cols:  { 지역:[3,3,7,...], 대학:[...], /* 사전 있는 열은 인덱스 배열, 나머지는 값 배열 */
           연도, 모집인원, 경쟁률, 추합, 변환50, 변환70, 만점, 등급50, 등급70,
           총지원지원, 합격인원, 실경쟁률 }
};
```

즉 `i`번째 행의 대학은 `dicts.대학[cols.대학[i]]`입니다. 결측은 `null`.

## 로컬 실행

빌드 없음. 파일을 열기만 하면 됩니다.

```bash
git clone https://github.com/jihugwak/susi-search.git
cd susi-search
python3 -m http.server 8000   # http://localhost:8000
```

`main`에 push하면 GitHub Pages로 자동 재배포됩니다.

## 데이터 파이프라인

원본은 Numbers 파일(`대학어디가(2023~2026)수시입결자료(남악고 김현석)ver0703.numbers`, 30MB)이고,
`numbers-parser`로 시트를 추출해 `data.js` / `links.js` / `grade.js`를 생성했습니다.
추출 스크립트는 저장소에 포함되어 있지 않습니다(원본 파일이 저장소 밖에 있음).

## 원본 데이터의 알려진 결함과 보정

원본 시트를 전수 감사해 아래를 사이트에서 보정했습니다. 데이터를 갱신할 때 같은 처리가 필요합니다.

- `서울15` 같은 지역 오입력 → `서울`로 정규화
- 2026학년도 미발표 대학이 `0`으로 기재 → `0`을 결측(–)으로 처리
- 자체등급변환 시트에서 **5등급 열은 백분위 89.9 아래, 9등급 열은 백분위 4.0 아래 39행**의 수식이 깨져 있음 → 등급 범위를 벗어난 값은 결측 처리하고 보간에서도 제외
- 변환점수 열의 `9999`(결측 표시, 전주대 2025 2건) → `null`
- 만점 열이 깨진 행 다수(신라대 2023 만점 6.3 등) → 변환점수가 만점의 105%를 넘으면 만점을 결측 처리. 5% 이내 초과(430행)는 가산점·반올림으로 보고 유지
- 소계열 미분류가 빈칸(1,312행)과 `0.0`(1,013행)으로 섞여 있음 → 로드 시 `0.0`을 빈칸으로 통합
- 대학링크 시트의 `학과안내자료` 열은 전 대학이 비어 있어 컬럼째 제거
- 대학자료의 `국어·수학·탐구·평균·영어` 열은 57,140행 중 15행만 채워져 있어 싣지 않음
- 대학자료 ↔ 대학링크의 캠퍼스 표기 불일치는 `app.js`의 `LINK_ALIAS`로 매핑 (`중앙대(다빈치)`→`중앙대2캠` 등)

## 한계

- **정시 자료 없음.** 원본의 정시결과 시트는 표 서식만 있고 데이터 행이 비어 있어 살릴 수 없었습니다.
- 데이터에 없는 대학: KAIST·POSTECH·UNIST·GIST·DGIST 등 과기원, 수원가톨릭대·광신대·영남신학대·영산선학대·예원예술대·한국전통문화대
- 축약 표기 주의: `한양대(에)`=한양대 ERICA, `연세대(미)`=연세대 미래, `국립한국교통대`, `가톨릭꽃동네대`
- 판정 기준(안정 = 컷−0.25 이하, 적정 = ±0.25, 도전 = +0.8 이내)은 임의로 정한 휴리스틱입니다.
