# 수시 입결 검색 사이트 만들기 (Claude용 작업 안내)

선생님이 준 입결 자료를 빈 양식에 넣어, **파일 하나로 동작하는 사이트**(`.html`)를 만듭니다.
선생님은 개발자가 아닐 수 있습니다. 쉬운 말로 설명하고, 터미널 명령을 시키지 마세요.

## 1. 키트 준비

`build.py`, `shell.html`, `sample.csv`가 필요합니다. 아래 순서로 시도합니다.

1. 대화에 `susi-site-kit.zip`이 첨부되어 있으면 압축을 풉니다.
2. 코드 실행 환경에서 받습니다.
   `git clone --depth 1 https://github.com/jihugwak/susi-search.git` 후 `susi-search/api/v1/` 사용
3. `https://jihugwak.github.io/susi-search/api/v1/manifest.json`의 주소에서 직접 받습니다.
4. 모두 실패하면 네트워크 제한일 수 있습니다. 선생님께 `https://jihugwak.github.io/susi-search/teachers.html`에서
   키트 zip을 받아 대화에 첨부해 달라고 요청합니다.

코드 실행을 쓸 수 없으면 설정의 코드 실행 및 파일 생성 기능을 켜 달라고 안내합니다.

## 2. 자료 확인

- 자료의 형식은 선생님마다 다릅니다. 엑셀, CSV, Numbers, 표가 든 PDF 모두 가능합니다.
- 어떤 시트와 열이 입결 자료인지 살피고, 등급 체계와 학년도 표기처럼 뜻이 불분명한 부분은 추측하지 말고 선생님께 묻습니다.
- **학생 이름, 학번, 개인 성적 등 개인정보가 있으면 사이트에 넣지 말고 선생님께 알립니다.** 사이트는 누구나 볼 수 있게 공개될 수 있습니다.
- 자료에 없는 수치를 채우거나 지어내지 않습니다. 없는 값은 빈칸으로 둡니다.

## 3. rows.csv 작성

UTF-8 CSV 한 행이 한 대학·전형·학과·학년도입니다. `sample.csv`와 같은 열 이름을 씁니다.

| 열 | 필수 | 뜻 |
|---|---|---|
| 대학 | 필수 | 대학 이름. 캠퍼스는 `연세대(미)`처럼 구분 |
| 연도 | 필수 | 학년도. 예: `2026` |
| 전형 | 필수 | 전형 이름 |
| 학과 | 필수 | 모집단위 |
| 지역 | | 예: `서울`, `경기`, `부산울산경남` |
| 교과/종합 | | 전형 유형. 보통 `교과`, `종합`, `논술`, `실기` 등 |
| 인문/자연 | | 계열 |
| 소계열 | | 세부 계열. 예: `간호`, `컴퓨터` |
| 모집인원, 추합, 합격인원 | | 인원 수 |
| 경쟁률, 실경쟁률 | | 숫자만. `8.5:1`은 `8.5` |
| 총지원지원 | | 총 지원자 수 |
| 등급50, 등급70 | | 최종등록자 50%, 70% 지점의 내신 등급 |
| 변환50, 변환70, 만점 | | 대학별 환산점수와 그 만점 |

자료의 일부 열만 있어도 됩니다. 없는 열은 생략합니다.

## 4. config.json 작성

```json
{
  "site_title": "OO고 수시입결검색",
  "source": "OO고 진학부 정리 자료 (2026년 3월)",
  "description": "링크 미리보기에 나올 한 줄 설명",
  "note": "푸터에 덧붙일 문구. 없으면 생략"
}
```

`site_title`과 `source`는 필수입니다. 자료의 출처를 모르면 선생님께 묻습니다.

## 5. 빌드

```bash
python3 build.py --rows rows.csv --config config.json --out 사이트이름.html
```

- `오류:`가 나오면 파일이 만들어지지 않습니다. 원인을 고쳐 다시 실행합니다.
- `주의:`는 파일이 만들어지지만 선생님께 그대로 전달할 내용입니다.
- 대학 링크와 등급 변환표는 기본값이 들어 있습니다. 선생님이 새 자료를 주면 `--links`, `--grade`로 교체합니다.
  링크 형식은 `{"대학":{"입학처홈페이지":"URL"}}`, 등급표 형식은 `[[백분위,9등급,5등급],...]`입니다.
- 사용자가 요청하지 않으면 `shell.html`의 화면이나 코드를 고치지 않습니다.

## 6. 검증과 전달

1. 원본 자료에서 행 수와 학년도를 세어 빌드 결과와 비교합니다. 임의의 3개 행은 원본과 값을 대조합니다.
2. 완성한 `.html` 파일을 내려받을 수 있게 전달합니다.
3. 선생님께 행 수, 학년도, 주의 사항, 대조 결과를 쉬운 말로 알립니다.
4. 사용 방법을 안내합니다.
   - 내 컴퓨터에서 보기: 파일을 더블클릭합니다.
   - 주소로 공유하기: Netlify Drop 같은 무료 호스팅에 파일을 올립니다. 파일 이름을 `index.html`로 바꿔 폴더째 올리면 됩니다.

## 7. 자료 갱신

다음 해에는 이전 `rows.csv`나 원본에 새 학년도 자료를 합쳐 다시 빌드하면 됩니다. 입결 수치는 지원 판단의 참고자료임을 사이트 푸터가 안내합니다.
